<img width="1426" height="772" alt="image" src="https://github.com/user-attachments/assets/131bed31-80ce-4327-a38e-cd0967c4a5a8" /># 🎯 Aimock – AI-Powered Interview Platform

Aimock is a modern web-based mock interview platform designed to help students and job seekers practice interviews in a realistic environment. Users can upload their resume and job description, customize interview settings, answer AI-generated questions using voice, and receive performance feedback with progress tracking.

---

## ✨ Features

- 📄 Upload Resume (PDF, TXT, MD)
- 💼 Upload Job Description
- 🎯 Role-based Interview Setup
- 🧠 Technical, Behavioral & Mixed Interview Modes
- 🎚️ Difficulty Selection (Fresher / Mid / Senior)
- 🎤 Voice-based Interview using Web Speech API
- 🔊 AI Question Narration (Text-to-Speech)
- 📝 Speech-to-Text Response Capture
- 📊 Performance Dashboard
- ⭐ Overall Score & Subscores
- 📈 Interview History & Progress Tracking
- 💡 Personalized Interview Tips
- 📥 Download Interview Report

## ⚙️ How It Works

1. User signs in.
2. Uploads Resume.
3. Uploads Job Description.
4. Selects:
   - Role
   - Interview Type
   - Difficulty
   - Number of Questions
5. AI generates interview questions.
6. Questions are spoken using Text-to-Speech.
7. Candidate answers using voice.
8. Speech Recognition converts responses to text.
9. Performance is evaluated.
10. Results, feedback, and history are displayed.

---

## 📊 Evaluation Parameters

The platform evaluates candidates using multiple metrics:

- Communication
- Confidence
- Relevance to Job Description
- Answer Depth
- Overall Performance Score

## 💻 Installation

Clone the repository:

```bash

```

Open the project folder:

```bash

```

Launch `index.html` in your browser.
